Player is a sentient spacecraft.

Interstellar travel happens via artificial wormholes. Wormholes limit mass passing through at a time.

# Crafting tree

Elements

- Element W: powers Wormhole Clasp. Incredibly rare. Gates player's ability to build probes and trucks.
- Element K: powers Kinetic Engine
- Structural Materials: stand-in for steel, titanium, etc
- Minerals: necessary for many things
- Crystals: also necessary for many things

Components

- Sensor and Communication Package: Minerals and Crystals
- Wormhole Clasp: Structural Materials
  - allows travel through wormholes, primary method of interstellar travel
- Kinetic Engine: Structural Materials + Minerals + Crystals
  - allows interplanetary travel

Equipment

- Astronomy Package: Structural Materials, Minerals, and Crystals
  - Reveals star types of neighboring stars, plus stochastic information about exoplanets

Bodies

- Probe: Sensor and Communication Package + Astronomy Package + Wormhole Clasp
  - Can only communicate back via a trail of beacons. Probes contain cargo of beacons.
- Beacon: Sensor and Communication Package + Structural Materials
- Orbital Storage: Structural Materials
- Truck: Structural Materials + Wormhole Clasp
  - Allows sending materials through wormholes (can go multi-hop)
- Spidermechs: Structural Materials
  - The drones that build things

# Storage

Player has limited storage space onboard. To store more materials than available onboard, they need to construct Orbital Storage.
